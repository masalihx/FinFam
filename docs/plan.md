## Baselines (с чем сравниваем)
| Задача | Baseline | Метрика |
|---|---|---|
| Категоризация | самая частая категория; ключевые слова | macro-F1, % |
| Перерасход | пропорция «потрачено × 30/d» | precision, recall, % |
| Купить / отложить | без расширения; правило 50/30/20; решение поверх пропорции | precision, recall, %; $ в месяц |
| Ассистент | ключевые слова | macro-F1, % |

## Если не успеваем, режем в таком порядке
1. PayPal Sandbox → только демо-данные (упоминаем как следующий шаг).
2. Кривая «обучение на исправлениях» → одна цифра «после 50 исправлений».
3. Ассистент в расширении → только на сайте.
4. ML 4 (намерения) → ключевые слова, без метрик.

**Не режем никогда:** ML 2 + бэктест, расширение с 🟢🟡🔴, README с baseline и ошибками, дисклеймер.

## Сон
Нужен хотя бы короткий. Лучшее окно — после шага 5 (бэкенд работает) или после шага 8. Время сдвигаем по запасу.
