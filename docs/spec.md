## Шаг 1. Основа продукта

### Рынок и язык ✅
- США, доллары. Интерфейс сайта, расширения и ассистента — на английском.

### Семья = комната ✅
- Родитель создаёт комнату и получает **код приглашения** (например `SMITH-4821`).
- Остальные регистрируются по **email + паролю** и вводят код.
- **Общее пространство (видят все):** общий семейный банк, прошлые и **предстоящие** расходы всей семьи, семейные цели.
- **Личное пространство (у каждого):** свои карманные деньги, свои траты и планы, свои цели.
  Личные траты детей **также входят в общие расходы семьи**: дети зависят от родителей, даже если сами зарабатывают.

### Источники данных ✅
- **PayPal (Sandbox):** расходы с карт.
- **Загрузка файлов, обработка через Gemini API (бесплатный):** фото чека, PDF-выписка банка, таблица CSV/Excel — Gemini извлекает траты.
- Ключ Gemini: команда получает на aistudio.google.com и сама вставляет в `.env` (`GEMINI_API_KEY=`).

### Демо-семья ✅
- **2 родителя + 2 подростка.** Общий семейный банк — синтетическая семья из открытого датасета (Misata, CC BY 4.0, 2 года, доход $117,700, аренда $1,940).
- В датасете нет разделения по членам семьи → личные пространства подростков генерируем (с пометкой в отчёте).

### Чья трата ✅
- **По источнику:** у каждого свой PayPal и свои загрузки → трата принадлежит тому, кто её подключил/загрузил.
- Для PayPal Sandbox: у каждого члена семьи свой тестовый аккаунт; транзакции относим по email плательщика/получателя, указанному в профиле.

### Карманные деньги ✅
- Родитель задаёт сумму в неделю или месяц.
- Подросток сам добавляет свой заработок (подработка, подарки).
- Перевод через PayPal Sandbox: родитель отправляет тестовые деньги на тестовый аккаунт подростка.

### Предстоящие расходы ✅
- **Регулярные платежи (ML):** модель находит аренду, подписки, счета и предсказывает дату и сумму следующего платежа; проверка на таблице регулярных платежей датасета.
- **Планы вручную:** «день рождения 20 декабря, $150».
- **Прогноз остатка месяца (ML):** сколько ещё уйдёт на каждую категорию и риск перерасхода.

## Шаг 2. ML-ядро

### Что делает ML ✅
- Даёт **советы**.
- **Обрабатывает файлы и фото** расходов (Gemini).
- **Вердикт по товару** (расширение: выделил товар и цену → «стоит или не стоит»), с объяснением.
  Опирается на то, что семья указала при старте: **нужные расходы** (налоги, учёба, кредит…) и **хотелки**.
- Оценивает именно **цену**: «билеты на концерт купить можно, но за $100 — не стоит».

### Цена сравнивается с ✅
- **привычками и бюджетом семьи** (сколько вы обычно платите за такое; лимит хотелок; цели) **и**
- **рыночной ценой похожих товаров** (открытый датасет Amazon Products 2023: 117 тыс. товаров с ценами, MIT).

### Старт: нужное и хотелки ✅
- После подключения данных **ML предлагает**: «Аренда $1,940 — нужное? Доставка еды $300 — хотелка?»; семья подтверждает и ставит лимиты.

### Вердикт ✅
- **Buy / Think about it / Not worth it** + **«Reasonable price for you: up to $65»**.
- Подросток проверяет товар → считаем по **семейному бюджету**.

### Сравнение ✅
- Gemini — ещё один baseline («маленькая бесплатная модель против большой LLM»). Ключ Gemini работает (`gemini-2.5-flash` и новее).

### Главная цифра для жюри ✅
- **$ избежанного перерасхода** в месяц на семью.

### Схема ML ✅ (5 частей, у каждой baseline + Gemini)
1. Категоризация трат → нужное / хотелка.
2. Регулярные платежи (предстоящие расходы).
3. Риск перерасхода к концу месяца.
4. Рыночная цена товара по названию.
5. Вердикт по товару (3 + 4 + привычки семьи), проверка бэктестом в $.

### Часть 4. Рыночная цена ✅
- **Модель-регрессия** по названию товара (не поиск соседей).
- В карточке: **диапазон «похожие стоят $80–150»**.
- Цены датасета — 2023 год, **без поправки на инфляцию, с пометкой** «prices as of 2023».

### Часть 5. Вердикт ✅
- **Not worth it**, если хотя бы одно: цена выше рыночного диапазона; высокий риск перерасхода; дороже, чем семья обычно платит за такое; отодвигает отстающую цель.
- **Один уровень строгости** (пороги подбираем на данных, без настройки).
- **Нужное** (школа, лекарства) судим **только по цене**: покупать можно, предупреждаем, если дороже рынка.
- **Reasonable price for you: up to $X** — считаем **только по бюджету**: максимальная цена, при которой бюджет месяца ещё в порядке.

### Код v1 ✅
- Проходим каждую модель вместе: показываю устройство и результат, команда решает, что менять.

## Решения, принятые без команды (команда попросила доделать самостоятельно) 🟨
Каждое можно поменять; ниже — что выбрано и почему.

### ML
- **Часть 4, гибрид:** вес нашей модели подобран на 200 валидационных товарах и получился 0,05 — гибрид почти целиком опирается на Gemini; наша модель — запасной вариант, если Gemini недоступен. Рыночная цена показывается только для товаров (покупки, уход, здоровье, учёба, продукты): для билетов, поездок, ресторанов в датасете Amazon нет аналогов, а Gemini даёт нелепые цены.
- **Часть 5, правила вердикта (подобраны на демо, записаны в `ml/verdict.py`):** «выше рынка» — только если дороже верхней границы диапазона больше чем на 10%; «высокий риск» — только если покупка сама поднимает риск хотя бы на 5 п.п. (иначе мелкая покупка при уже высоком риске получает «Think about it»); «дороже обычного» — 90-й перцентиль покупок семьи в категории за 12 месяцев.
- **Часть 2:** Gemini-сравнение для регулярных платежей и категоризации сделано на выборках по 100–200 штук (лимиты бесплатного тарифа).
- **Часть 3 (перерасход)** оставлена из v1: её проверка была честной (время, baseline, ошибка с доходом найдена и исправлена).

### Комната и аккаунты
- Email + пароль (PBKDF2), сессия в cookie для сайта и токен для расширения. Код приглашения вида `CARTER-5626`.
- Права: семейные цели и настройки «нужное/хотелки» меняют только родители; подросток видит общий банк и свои данные; личное пространство подростка открывает только он сам и родители.
- Демо-вход без пароля (кнопки Alex/Sam/Maya/Leo) — только для локального демо.

### Сайт
- Шаблон: боковое меню (Family: Overview, Upcoming, Goals, Transactions · Me: My space, Check a purchase, Postponed, Add data · Room: Settings), чат-кнопка «Ask FinPilot» справа внизу, код приглашения под названием семьи.
- Мастер «Needs & wants» открывается баннером на главной у родителя, пока настройка не подтверждена.
- Демо-семья уже исправила две ошибки модели (проценты по кредитке → Bank fees, Macy's → Shopping) — так выглядит приложение после пары правок.

### Расширение
- Вход в окне расширения (или демо-персона). Карточка справа внизу; 🟢 сворачивается в значок, 🟡/🔴 раскрываются. Выделить товар и цену → правый клик → «Is this worth it? (FinPilot)».

## v3: всё в расширении (решения команды, 15 ноября) ✅
- **Весь функционал переезжает в расширение Chrome, без сервера.** Сайт v2 остаётся в репозитории как предыдущая версия.
- **Семейная комната = профили на одном компьютере** (как в Netflix): Alex, Sam, Maya, Leo с PIN-кодом и ролями. Синхронизация между компьютерами — в «Что дальше».
- **ML считает, Gemini объясняет.** Риск перерасхода, рыночная цена, регулярные платежи и категории считают наши модели, перенесённые в JavaScript и работающие прямо в браузере.
- **Gemini «обучаем» через контекст, а не fine-tuning.** Fine-tuning в Gemini API недоступен с мая 2025 (только платный Vertex AI). Вместо этого Gemini получает инструкцию с правилами семьи, примеры из наших датасетов и наши ML-модели как инструменты (function calling). Проверяем, насколько это улучшает Gemini по сравнению с Gemini без контекста.
